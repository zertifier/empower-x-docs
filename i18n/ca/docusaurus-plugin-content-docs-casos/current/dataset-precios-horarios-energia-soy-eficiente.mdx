# Preus Horaris d'Energia Elèctrica per Tarifa

*(Hourly Electricity Prices by Tariff – Soy Eficiente)*

## Descripció detallada

Aquest producte de dades **centralitza, normalitza i valoritza** la complexa informació dels preus del mercat elèctric espanyol procedents de fonts oficials (REE, OMIE). A través d'Empower-X, ofereix accés a un històric detallat amb resolució horària, segmentat per les diferents tarifes d'accés (des de 2.0TD fins a 6.3TD) i desglossat per zones geogràfiques.

Aquest cas d'ús actua com una **font de veritat (Trusted Data Provider)**, permetent a comercialitzadores, gestors energètics i prosumidors integrar aquesta informació en les seves simulacions de factures i estratègies de compra. En combinar-se amb altres conjunts de dades mitjançant Compute-to-Data, facilita l'entrenament d'algoritmes de flexibilitat de la demanda i el desplaçament automàtic de càrregues a hores vall, impulsant l'estalvi econòmic de forma segura i interoperable.

# Cases

In this section you will find the currently available use case in the Empower‑X energy dataspace, deployed for the integration, traceability, and analysis of energy data in the Positive Energy District (PED) of Rubí (Catalonia, Spain). The use case is a private, non-downloadable, and optimized dataset (hourly resolution and monthly filtering) that serves as the base input for running algorithms under Compute‑to‑Data.

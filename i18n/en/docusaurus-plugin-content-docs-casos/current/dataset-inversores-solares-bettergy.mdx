# Solar Inverter Monitoring and Management

*(Monitorización y Gestión de Inversores Solares – Bettergy)*

## Detailed description

This use case enables **advanced monitoring of photovoltaic assets** by integrating precise technical data from multiple solar inverter manufacturers. Through Empower-X, key metrics for energy generation, consumption, grid surplus, and performance statistics (Performance Ratio) are exposed in a standardized format.

By leveraging **Compute-to-Data** technologies, operations and maintenance (O&M) companies and software developers can run predictive maintenance algorithms, anomaly detection, and efficiency analytical models directly where the data resides. This ensures full data sovereignty and privacy for the facility while fostering the creation of new value-added services to optimize the renewable energy ecosystem.
